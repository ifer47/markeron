# MarkerOn v2.3.0 → v2.33.0 更新功能总结与视频脚本

> 对照基准：2026-07-22 的 v2.3.0（B 站教程 BV17ygy67ETV）→ 2026-11-23 的 v2.33.0。
> 本文只讲「上次视频之后新增或补上的能力」，不按版本流水账。

---

## 一、一句话概览

上次视频讲了 **9 种工具**，现在界面上是 **11 种**：补上了**选择与批量编辑**；笔迹加入了**毛笔字效果**；同时把**长按拉直、双模式橡皮擦、激光笔书写、深色主题、退出后留在桌面**这一整套交互补齐。

### 这次最值得演示的 5 件事

1. **`V` 选择工具** —— 框选、整组拖动、缩放、旋转、复制粘贴、批量删除。
2. **文字 / 序号也能缩放旋转** —— 文字可横向拉伸，序号可拉成椭圆，旋转后文字仍能双击改字。
3. **毛笔字效果** —— 慢写粗、快划细，起收笔带锋；默认开启，可在设置里关闭。
4. **长按拉直** —— 画歪了停半秒自动变直，还能继续拖动调终点。
5. **退出后留在桌面** —— 讲完一页按 `Esc` 把笔迹留在屏幕上，直接操作下层应用。

## 三、新增与补上的功能

### 1. 选择工具与批量编辑（`V`）

这是 2.3.0 之后最大的一块新能力，也是补充视频最值得重点演示的部分。

- 按 `V` 进入选择，**框选或点选**标注；按住 `Shift` 加选。
- **整组拖动**移动；方向键微调 1px，`Shift` + 方向键一次 10px。
- **角点缩放**：拖四角；`Shift` 等比缩放，`Alt` 以中心为基准缩放。
- **旋转**：拖选择框顶部圆点；`Shift` 按「吸附角度步进」吸附（默认 15°，可在设置中改为 1–90°）。
- **弯曲**：选中直线 / 箭头 / 被长按拉直锁定的手绘笔迹后，拖中点可拉成曲线（弯曲箭头）。
- **重设样式**：选中后按 `Q` / `E` 改颜色，`Ctrl` + 滚轮改线宽或字号，`D` 改线型。
- **文字与序号可缩放旋转**：角点可自由拉伸——文字横向拉伸，序号会拉成椭圆；`Shift` 等比，`Alt` 中心缩放；旋转后仍可双击文字原位编辑。
- **复制粘贴**：`Ctrl+C` / `Ctrl+V` 复制粘贴选中内容，连续粘贴按 12px 级联偏移，粘贴后自动选中，可直接拖动。
- **双击 `V` 全选**，再双击取消全选；`Delete` / `Backspace` 删除；`Esc` 清空选中。
- 说明：有选中时 `Ctrl+C` 复制选区，没有选中时仍复制整屏；白板模式下复制白板。

### 2. 序号工具（`N`，上次视频漏讲的第 11 种）

- 按 `N` 选中序号工具，点击画布放置编号标记。
- 再按 `N` 在 **数字（1、2、3…）** 与 **字母（A、B、C…，Excel 式 AA/AB）** 之间切换。
- `Shift+N` 重置当前计数，方便一轮新的讲解重新从 1 / A 开始。
- 字号与文字工具共用九档；选中后也能缩放、旋转。

### 3. 笔迹手感与绘制增强

- **毛笔字效果**：画笔粗细随书写速度变化（慢写粗、快划细），起笔收笔带锋；只对画笔生效，荧光笔保持等宽，直线 / 箭头 / 矩形 / 椭圆和被长按拉直的线不带笔锋。鼠标、触控、手写笔都生效；默认开启，可在「设置 → 常规 → 毛笔字效果」关闭。
- **长按拉直**：画笔 / 荧光笔画线时停住约 **0.5 秒**（位移不超过 10px）即锁定为直线，可继续拖动预览终点；只对「接近直线」的笔迹生效，闭环和折角会保留手绘形状。`Alt` 拖动可立即画精确直线并按角度吸附。
- **压感笔迹**：数位笔 / 触控笔按压力改变粗细；鼠标没有压力，粗细由笔速和起收笔决定（毛笔字效果）；关闭毛笔字后画笔恢复普通圆头笔迹（数位笔仍按压力变化）。
- **圆角与笔尖扫掠**：快速转折处做圆角处理，笔尖沿笔迹中心线扫掠，不再出现多边形折角。
- **线型切换**：按 `D` 循环 实线 → 虚线 → 点线，`Shift+D` 反向；适用于画笔、直线、箭头、矩形、椭圆，选中图形时直接改选中项。
- **笔宽九档**：`Ctrl` + 滚轮在九档几何步进线宽（1.15–9.2px）间切换；画笔 / 激光 / 箭头 / 矩形 / 椭圆 / 直线共用一组，荧光笔、橡皮擦各自独立，文字与序号共用字号；选中对象时直接改选中项。
- **正圆与圆心**：`Shift+Alt` 画正圆时以按下点为圆心；接近正圆的椭圆会自动画出圆心十字标记，讲几何时很方便。

> **录制注意**：`自动拉直`（抬笔时把接近笔直的笔迹自动修正）已经移除。现在只有「长按拉直」，视频里不要演示或口播自动拉直。

### 4. 橡皮擦与鼠标手势

- **按住右键临时擦除**：绘制中按住鼠标右键即擦除，松开自动恢复原工具，不再需要先切换工具（穿透模式和文字输入时不触发）。
- **橡皮擦双模式**：选中橡皮擦后再按 `7`（或再点一次工具栏橡皮擦）在「轨迹擦除」和「对象擦除」间切换；对象擦除划过即删除整个图形或文字，两者都可撤销。
- **橡皮擦细节**：独立线宽；光标改为橡皮擦字形；对象擦除的判定范围与光标字形一致。

### 5. 激光笔与自动回画笔

- **激光笔书写模式**：设置 → 常规 → 激光笔模式可选「拖尾 / 书写」。书写模式下连续书写笔迹一直保留，笔画之间短暂停顿也不会消失；停笔约 1 秒后整体淡出（400ms），适合边讲边写、不想留痕的场景。
- **画完图形回到画笔**：开启后，用直线 / 箭头 / 矩形 / 椭圆画完一次自动切回画笔；再次进入标注也从画笔开始；用修饰键临时切工具时仍恢复到切换前的工具。

### 6. 白板与桌面留存

- **画板颜色**：白板模式可选 **白板 / 黑板**，只影响白板，不影响屏幕叠加。
- **退出后保留绘制内容**：开启后，用快捷键关闭标注时笔迹留在桌面并成为可穿透层（可操作下层窗口），再按快捷键回到编辑；绘制中按一次 `Esc` 留下笔迹，再按一次才完全收起，内容仍保留。切换应用后该行为依然有效。
- **穿透模式回到绘制**：穿透模式下按 `Esc`（标注层仍持有键盘焦点时）或全局「开始标注」快捷键即可回到绘制，不会丢掉笔迹。
- **按 `W` 切换时保留**：在标注模式内切换屏幕 / 白板时不重置画布（默认开启）。

### 7. 外观与个性化

- **外观主题**：设置 → 常规 → 外观可选 **深色 / 浅色 / 跟随系统**；设置窗口原生标题栏、标注层 UI、Windows 托盘图标同步跟随。
- **自定义吸附角度**：吸附角度步进从固定档位改为 **1–90° 滑杆 + 数字输入**，画特定角度、旋转图形时更精确。
- **快捷键提示**：工具栏按钮悬停显示快捷键；帮助面板统一为「一行一个快捷键」。
- **重复点选工具切换光标**：再次点击已选中的画笔可切换笔形 / 圆点光标；箭头 / 矩形 / 椭圆 / 直线 / 激光再按同键可切换十字 / 圆点光标。

### 8. 工程与体验

- **设置跨版本保留**：升级后自动保留快捷键、外观、画笔粗细、工具栏位置等设置；安装版 / 微软商店版 / 绿色版之间切换也会迁移原配置。
- **复制截图可直接落盘**：Windows 上 `Ctrl+C` 复制屏幕后，在资源管理器里 `Ctrl+V` 可直接粘贴出图片文件。
- **应用诊断**：设置 → 应用诊断可导出诊断包（操作记录 + 环境 + 设置，不含账号与绘画内容），一键打开 GitHub Issue 反馈。
- **赞助方式**：微信 / 支付宝收款码；新增「致谢」入口（远程获取，v2.33 时名为「赞助名单」）与致谢滚动。

## 四、稳定性与兼容性改进

这些不需要在视频里逐条讲，口播一句「顺手修了一堆兼容性问题」即可，需要时挑几条说：

- 视频会议 / 播放器上标注导致的黑屏修复。
- 长笔画实时预览改为分段冻结，大量绘制时明显更跟手。
- 闲置后透明丢失、DPI 缩放错位、黑屏与笔迹跳变修复。
- 全屏应用上开启 / 退出标注时任务栏不再冒出或闪烁。
- Windows 单实例在「僵尸进程 / 主实例卡死」时能自动接管。
- 系统文本缩放下工具栏显示不完整、弹出位置偏移修复。
- macOS：处理过的快捷键不再触发系统提示音；改用原生截屏避免重复弹「屏幕录制」授权。
- 激光笔急转弯笔迹平滑；独立工具栏不再被数位笔拖动带跑。

## 五、补充视频脚本建议（约 12 分钟）

> 定位：**「2.3.0 之后，我们又更到了 2.33。」** 开场先给结论，再按「选择 → 工具 → 手感 → 白板 / 外观」顺序演示，最后讲工程改进。

### 0. 开场（0:00–0:40）

- 口播要点：上一个视频讲的是 2.3.0 的 9 种工具和基础用法；这期只讲新增和补上的，老功能不重复。
- 钩子：**「工具从 9 种变成 11 种，最值得学的是按 V 的那个选择工具；笔迹也比以前更像笔了。」**

### 1. 选择工具：一次改一整片（0:40–3:20）

演示动线：

1. 画三四个图形和一段手写 → 按 `V` 框选 → 整组拖走。
2. 点选单个 → 拖角点放大（`Shift` 等比、`Alt` 中心）→ 拖顶部圆点旋转（`Shift` 吸附）。
3. 选中箭头 → 拖中点弯成弧线。
4. `Q` / `E` 换色、`Ctrl` + 滚轮改粗细、`D` 改虚线。
5. 选中文字 → 拖角点横向拉伸；选中序号 → 拖角点拉成椭圆；旋转后双击文字继续改字。
6. `Ctrl+C` / `Ctrl+V` 复制一份（会偏移 12px 并自动选中）。
7. 双击 `V` 全选 → `Delete` 删除；再按 `Esc` 取消选中。

口播关键句：**「以前删一个标注要擦半天，现在框一下、按 Delete 就没了。」**

### 2. 序号工具：讲解顺序一目了然（3:20–3:55）

- 按 `N` 连续点击 1、2、3；再按 `N` 切成 A、B、C；`Shift+N` 归零。
- 场景：讲流程、讲步骤、讲代码行号；选中序号还能放大、旋转。

### 3. 笔迹更「像笔」（3:55–6:40）

1. **毛笔字效果**：慢慢写一段、快速划一段，对比粗细和起收笔的锋；再到设置里关掉「毛笔字效果」对比等宽圆头；说明荧光笔始终等宽。
2. **长按拉直**：慢慢画一条歪线，停住 0.5 秒 → 变直线，继续拖可调终点；画个圈停住不会塌（只对接近直线的笔迹生效）。
3. **`Alt` 立即直线** + 角度吸附（设置里可把步进改成 1°–90°）。
4. **压感**：用数位笔（没有就用鼠标演示速度变化），说明鼠标靠笔速、数位笔靠压力。
5. **线型** `D` / `Shift+D`：实线 → 虚线 → 点线。
6. **笔宽九档**：`Ctrl` + 滚轮，展示工具栏九档预览。
7. **正圆**：`Shift+Alt` 以按下点为圆心；画到接近正圆时，圆心自动出现十字标记。

> 这一段**不要提自动拉直**——该功能已经移除，只有长按拉直。

### 4. 橡皮擦：不用先切工具（6:40–7:25）

- 任意绘制中**按住右键**擦，松开继续画。
- 选中橡皮擦后再按 `7`：轨迹擦除 ↔ 对象擦除（整段删除）。
- 提一句：橡皮擦有独立粗细，光标就是橡皮擦形状，对象擦除范围与光标一致。

### 5. 激光笔与自动回画笔（7:25–8:10）

- 设置 → 常规 → 激光笔模式 → **书写**：连续写不消失，停笔 1 秒整体淡出。
- 打开「画完图形后回到画笔」：画完箭头自动回画笔，连续画多个箭头不用反复按 `3`；用修饰键临时切工具后仍回到原工具。

### 6. 白板与「留在桌面上」（8:10–9:55）

- 设置 → 常规 → 白板与内容 → **画板颜色：白板 / 黑板**。
- 打开「退出后保留绘制内容」：按快捷键退出 → 笔迹留在桌面且可穿透点下层；再按快捷键回来继续编辑。
- 绘制中按一次 `Esc` 留笔迹，按两次完全收起（内容保留）。
- 穿透模式下按 `Esc` 或开始标注快捷键回到绘制，不会丢笔迹；切换应用后 Esc 仍然有效。
- 提一句「按 W 切换时保留」默认开启。

### 7. 外观与设置（9:55–10:55）

- 外观：深色 / 浅色 / 跟随系统（设置窗口和托盘图标一起变）。
- 工具栏悬停显示快捷键；帮助页一行一个快捷键。
- 吸附角度改成 1–90° 自定义。
- 重复点选画笔 / 形状工具切换光标样式。
- 提一句：升级后设置自动保留，安装版 / 商店版 / 绿色版互切也会迁移。

### 8. 工程改进与收尾（10:55–12:00）

- 复制屏幕后可直接在资源管理器 `Ctrl+V` 得到图片文件（Windows）。
- 应用诊断：导出诊断包 + 一键提 Issue。
- 兼容性：视频会议 / 播放器不再黑屏、长笔画更跟手、全屏应用任务栏不闪、Windows 单实例自恢复、macOS 不再响提示音 / 反复要录屏权限。
- 收尾：下载渠道（官网 / GitHub Releases / 微软商店 / WinGet / 绿色版）、Star、B 站三连；下一个视频可以讲「选择工具 + 白板」的组合玩法。
